Política de privacidad

Esta web guarda un apodo y un ID de usuario generado automáticamente para permitir el acceso al servicio.
No se recogen datos personales como nombre, dirección o teléfono.
Los datos no se comparten con terceros ni se utilizan para publicidad.
El usuario puede solicitar la eliminación de su cuenta en cualquier momento.
Si eres menor de 14 años, debes usar esta web con la autorización de tus padres o tutores.
