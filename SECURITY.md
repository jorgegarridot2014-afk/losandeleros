# Security Policy

## Supported Versions
Estas son las versiones que reciben actualizaciones de seguridad:

| Versión | Estado             |
|--------|---------------------|
| main   | ✔ Soportada         |
| 1.x    | ✔ Soportada         |
| 0.x    | ✘ No soportada      |

## Reporting a Vulnerability

Si encuentras una vulnerabilidad en este proyecto:

1. **No abras un issue público.**
2. Envíame un mensaje privado a: **jorgegarridot2014@gmail.com**
3. Incluye:
   - Descripción del problema  
   - Cómo reproducirlo  
   - Impacto potencial  
   - (Opcional) una posible solución  

Responderé en un plazo de **48–72 horas**.

## Responsible Disclosure

Por favor no publiques detalles de la vulnerabilidad hasta que se haya corregido.
